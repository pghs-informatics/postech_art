## 작품 속 수학과 AI
- 가중치 그래프: 연결의 수와 연결의 굵기는 다르다
- 추천 점수식: `최근 활동량` vs `예전 친밀도 × 감소율`
- 선호적 연결(Barabási·Albert, 1999): 활동량 순 추천이 만드는 부익부 구조
- 편집 거리(Levenshtein, 1966)
- 텍스트 유사도: 직접 쓴 문장과 기억의 2-gram 코사인 유사도
- 데이터 소니피케이션: 연결의 굵기를 화음으로

※ 8주 시뮬레이션은 규칙을 단순화한 가상 모델이며 실제 사용자 데이터가 아닙니다.
